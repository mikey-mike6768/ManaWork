# ManaWork — Delivery Roadmap

## Milestone 1: Foundation

- [ ] Establish Flutter app structure and design system.
- [ ] Configure Supabase environments and client initialization.
- [ ] Add database migrations and Row Level Security policies.
- [ ] Implement authentication and profile bootstrap.
- [ ] Support English, Telugu, and Hindi.
- [ ] Add Customer and Worker modes with starter dashboards.

## Milestone 2: Marketplace

- [ ] Build service category and skill catalogue.
- [ ] Implement worker onboarding and verification workflow.
- [ ] Capture worker service areas and availability.
- [ ] Add location-aware worker discovery.
- [ ] Implement service requests, quotes, assignment, and booking status.

## Milestone 3: Payments and communication

- [ ] Integrate a payment provider after business and compliance decisions.
- [ ] Add server-verified, idempotent payment webhooks.
- [ ] Add booking notifications and push notifications.
- [ ] Add customer-worker conversations and booking updates.
- [ ] Define cancellation, refund, commission, and payout rules.

## Milestone 4: Trust, operations, and launch

- [ ] Build admin workflows for verification, reports, and disputes.
- [ ] Add ratings, reviews, and audit trails.
- [ ] Add operational dashboards and support tooling.
- [ ] Complete security, privacy, and abuse testing.
- [ ] Run a controlled pilot in Gachibowli, Madhapur, Kondapur, and Kukatpally.

## Launch service categories

- Housekeeping and domestic help
- Plumbing and electrical services
- Drivers
- Construction labour

## Release principle

Ship a secure, narrow pilot first. Expand categories and geography only after worker quality, fulfilment reliability, customer support, and unit economics are measured.
